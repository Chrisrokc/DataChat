Welcome to DataChat

This installer sets up DataChat on your Mac as a background service that starts automatically at login. When it finishes, your browser will open to the first-run Setup Wizard at http://localhost:5159.

You will be asked:

  • Database: run a local SQL Server 2025 in Docker (requires Docker Desktop), or connect to an existing SQL Server 2025 instance.
  • Admin account & AI provider (OpenAI / Azure OpenAI / Ollama) — configured in the wizard.

Note: this build is not signed. You may need to right-click and choose Open the first time to bypass Gatekeeper.
